# Fuentes

Todas las fuentes de esta carpeta usan la licencia libre **SIL Open Font License 1.1**
(se pueden usar y distribuir gratis). Vienen de [Fontsource](https://fontsource.org):

- Instrument Serif — títulos
- Cormorant Garamond — texto de la carta
- Pinyon Script — nombres y firma (caligrafía)
- Geist — interfaz

Están incluidas en el proyecto para que la página se vea igual aunque no haya internet.
